# Портал сайтів і підтримки

Laravel-портал для обліку сайтів, компаній, FTP та хостингів, Telegram-підтримки, моніторингу вибраних Prod/Dev і погодженого дистанційного керування сайтами.

- Ролі Admin, PM, Developer, Manager; серверні перевірки прав і підтвердження користувачів.
- Access-бот: одноразове підключення з кабінету, доступ лише активним дозволеним користувачам.
- Support-бот: тікети, історія повідомлень, статус доставки, повторне надсилання.
- Моніторинг зі списку «Сайти»: cron без постійних воркерів, історія, інциденти, сповіщення відповідальним.
- Окремі середовища Prod/Dev, бізнес-статуси та режим iframe для 3D.
- Керування дочірніми сайтами через HTTPS, індивідуальні ключі та версії команд. Віддаленого видалення немає.

## Розробка

PHP 8.2+ з cURL, PDO MySQL та SQLite для тестів, Composer, Node.js. Залежності встановлюються через Composer та npm. Для нового середовища скопіювати .env.example, налаштувати базу, APP_URL та APP_KEY, виконати міграції. На наявному середовищі зберігати APP_KEY та користуватися інструкцією розгортання; не запускати UserSeeder повторно.

Команди:

~~~bash
composer install
npm ci
npm run build
php vendor/bin/phpunit
~~~

Тести примусово використовують SQLite у пам’яті та підмінені HTTP-запити. Створювати тестові дані у робочій базі не потрібно.

## Структура

app/Modules/TelegramAccess і TelegramSupport містять конфігурацію, маршрути, консольні команди, транспорт і обробники відповідних ботів. Monitoring відповідає за обхід та інциденти; Site — за облік і керування сайтами. Shared містить спільні перевірки прав та безпечний HTTP-клієнт.

Старі domains/checks/settings замінені моніторингом Site. Перед застосуванням міграцій потрібна резервна копія бази. Автоматичне остаточне видалення записів вимкнене; кошик очищає адміністратор явно.
