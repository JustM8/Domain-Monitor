# Пам’ятка для задач цього проєкту

Актуалізовано: 2026-09-19. Це стислий контекст; фактичну поведінку звіряй із кодом, який змінюєш.

- Проєкт — внутрішній Laravel-портал обліку сайтів, компаній, доступів, Telegram-підтримки, моніторингу та дистанційного керування.
- Код у цьому середовищі: `D:\OSPanel6\home\adm.chk`. Папка `C:\Users\Mate\Documents\ChatGPT\adm.ck` є папкою задачі, а не копією застосунку.
- Стек: PHP 8.2+, Laravel 10, Blade, Bootstrap 5, Vite, Chart.js. Функціональні модулі: `app/Modules`; шаблони: `resources/views/portal`; локалізація: `lang`.
- Почни з [контексту](docs/PROJECT-CONTEXT.md); для потрібної області відкрий [карту модулів](docs/MODULE-MAP.md). Не скануй весь проєкт повторно без потреби.
- Для моніторингу прочитай [аналіз і план](docs/MONITORING-PLAN.md): там чітко відділено поточний код від пропозицій.
- `Site` — основний реєстр. `site_type`, `environment`, бізнес-статус, `remote_control_enabled`, бажаний `is_active` і виміряна доступність — різні поняття.
- Автоматичний моніторинг зараз охоплює всі невидалені Prod, незалежно від керування; Dev перевіряються вручну. Команда `monitoring:run`, прямий cron; Laravel scheduler для неї порожній.
- Поточний відсоток — успішність перевірок, не часовий uptime. Інцидент після 2 невдач; Telegram через Access-бота вибраним Admin/PM. Планове вимкнення потребує підтвердження поточної версії команди.
- Контроль доступу: `app/Modules/Shared/Support/PortalAccess.php` і middleware маршрутів. Перевірки прав мають лишатися на сервері.
- Зберігай `SafeHttp` / `OutboundAddressPolicy`, перевірку TLS, версії команд та захист від застарілих відповідей. Моніторинг не має автоматично вимикати сайти.
- Не записуй секрети з `.env`, паролі чи ключі в документацію/логи. На наявній базі зберігати `APP_KEY`; загальний `db:seed`/`UserSeeder` може змінити доступи. Перед змінами схеми користуйся `docs/DEPLOYMENT.md`.
- Тести: `php vendor/bin/phpunit`; `phpunit.xml` примусово задає SQLite `:memory:`, тестові налаштування, `Tests/TestCase.php` забороняє непідмінені HTTP-запити. Збірка UI: `npm run build`.
- Стан 2026-09-19: виконано аналіз і написано документацію; запропоновані доробки моніторингу ще НЕ реалізовано. Фактичний cron на хостингу не перевірений.
- Після суттєвих змін онови відповідний документ і дату; не називай пропозиції реалізованими до перевірки.
