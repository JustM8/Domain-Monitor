# Пам’ятка для задач цього проєкту

Актуалізовано: 2026-09-19, після патча моніторингу.

- Проєкт — Laravel-портал обліку сайтів, компаній, доступів, Telegram-підтримки та дистанційного керування. Код: `D:\OSPanel6\home\adm.chk`; папка `C:\Users\Mate\Documents\ChatGPT\adm.ck` лише вказує на нього.
- PHP 8.2+, Laravel 10, Blade, Bootstrap, Vite. Модулі: `app/Modules`; UI: `resources/views/portal`.
- Почни з [контексту](docs/PROJECT-CONTEXT.md) та [карти модулів](docs/MODULE-MAP.md), далі читай лише потрібний сервіс і тести.
- Моніторинг реалізований; поточна поведінка й оновлення хостингу — [MONITORING-PATCH.md](docs/MONITORING-PATCH.md); точний FTP-перелік — [MONITORING-DEPLOY.md](docs/MONITORING-DEPLOY.md). [MONITORING-PLAN.md](docs/MONITORING-PLAN.md) зберігає початковий аналіз та статус етапів.
- Site — єдиний реєстр. site_type, environment, бізнес-статус, дозвіл remote_control_enabled, бажаний is_active та виміряна доступність — різні речі.
- monitoring_enabled визначає обхід cron незалежно від Prod/Dev і дозволу керування. Прямий cron `monitoring:run` рекомендовано щохвилини; Laravel scheduler порожній.
- Інтервал, timeout, поріг невдач, очікуваний код/текст, URL і відповідальні налаштовуються для сайту. Ручні перевірки — діагностика: не змінюють розклад, агрегати чи інциденти.
- Часова історія: monitoring_periods (активні періоди), monitoring_spans (обмежені спостереження), monitoring_metrics (денні гістограми). Ці таблиці зберігаються довгостроково. Старим лічильникам не приписуються часові метрики.
- Один результат дійсний не більше 2 інтервалів; далі unknown. Доступність = up/(up+down), покриття рахується окремо. Час UTC; календарні звіти Europe/Kyiv.
- Моніторинг не вимикає сайтів. Для від’єднання керованого сайту з виконаними/непідтвердженими командами потрібне підтвердження актуального active. Зміни цілі/налаштувань захищені monitoring_revision від застарілих HTTP-результатів.
- Права: `Shared/Support/PortalAccess.php`. PM змінює параметри у розділі моніторингу; Developer редагує картку, але не отримує sites.control.
- Зберігати SafeHttp / OutboundAddressPolicy, TLS, захист адрес, версії команд. Секрети не записувати в документи/логи; APP_KEY не міняти на наявному середовищі; загальний UserSeeder не запускати повторно.
- Перевірки: `php vendor/bin/phpunit`, SQLite :memory:, HTTP/Telegram підмінені. Локально PHP 8.3: `D:\OSPanel6\modules\PHP-8.3\php.exe`; за потреби передати `-d sys_temp_dir=...` з чинним тимчасовим каталогом.
- Результат патча: 54 тести, 389 assertions; перевірено форми й звіти через HTTP-тести. Хостинг/MySQL/реальні Telegram/cron не змінювалися.
- Після суттєвих змін онови ці тези та профільний документ.
